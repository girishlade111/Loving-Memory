# Loving Memory — A Tribute Page

A single-file, static tribute page: **"In Loving Memory of Sadashiv Tukaram Lade."** An elegant, responsive memorial website where family and friends can read a tribute, watch a tribute video, and leave their own tributes.

## What it does

- **Tribute hero section** with the memorial dedication
- **Tribute section** with biographical tribute text
- **Tribute video** section
- **Tributes wall** where visitors can leave messages of remembrance
- Fully responsive, elegant serif typography (Lora + Lato)

## Tech stack

- Plain HTML5, CSS, and JavaScript (single `index.html`)
- Tailwind CSS (via CDN) for styling
- Lucide icons (via CDN)
- Google Fonts (Lora, Lato)

No build step, no dependencies, no backend.

## Quick start

Just open `index.html` in a browser, or serve it with any static server:

```sh
npx serve .
# or
python3 -m http.server
```
